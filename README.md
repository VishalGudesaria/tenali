# Newton's Laws of Motion — Interactive Physics Lab

An ICT project website built with HTML, CSS and JavaScript. It contains explanations of Newton's three laws, an F=ma slider simulation, real-life examples, a quiz, and editable project details.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive styling
- `script.js` — simulation and quiz behavior

## Personalize before submitting
In `index.html`, find the **About this project** section and replace:
- Your Name
- Your Institution

You can also edit the title or text to suit your teacher's requirements.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com
2. Click the **+** icon (top right) → **New repository**.
3. Repository name: `newton-laws-physics-lab`
4. Set it to **Public** (GitHub Free supports Pages from public repositories).
5. Click **Create repository**.
6. On the new repository page, click **Add file** → **Upload files**.
7. Extract this ZIP on your computer. Upload the three website files (`index.html`, `style.css`, `script.js`) and `README.md` from the extracted folder. Do not upload the ZIP itself.
8. Click **Commit changes**.
9. Open repository **Settings** → **Pages**.
10. Under **Build and deployment**, choose **Deploy from a branch**.
11. Choose branch **main**, folder **/(root)**, then **Save**.
12. Wait a few minutes, refresh Pages settings, and click **Visit site** when the URL appears.

Your site URL will look like:
`https://YOUR-GITHUB-USERNAME.github.io/newton-laws-physics-lab/`

GitHub Pages may take several minutes to publish after you save. Keep your repository public if using GitHub Free.
